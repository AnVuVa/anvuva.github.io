Biology-Guided Local-Global Residual Propagation for Spatial Gene Expression Prediction from Histology

Vu Van An, Nguyen Duy Long, Ho Viet Duc Luong, Nguyen P. Binh

Accepted WACV2027 (Core A)

BiotechnologyComputational Pathology

Abstract: Spatial transcriptomics provides spatially resolved molecular profiling, but its cost, limited throughput and experimental complexity hinder routine large-scale use. Predicting spatial gene expression from hematoxylin-and-eosin-stained histology images offers a scalable alternative, yet remains challenging because histology provides only an indirect morphological view of molecular activity. Existing methods typically decode expression from visual features in a single stage, even when enhanced with spatial aggregation, retrieval or multi-resolution fusion. This formulation is restrictive because spot-level expression reflects not only local morphology but also cellular identity, neighborhood composition and tissue-level organization. We propose BCARP, a Biology-guided Context-Aware Residual Propagation framework for histology-guided spatial transcriptomics prediction. Instead of directly predicting gene expression from histology embeddings, BCARP treats them as morphology visual priors and progressively refines spot representations in a transcriptomics-oriented latent space. Each refinement step integrates nuclei-guided local cellular context with prototype-guided global context propagation, enabling information exchange across both neighboring and spatially distant spots. A pattern-scale decoder further separates spatial expression into pattern prediction from raw expression with scale calibration. Evaluated on three ST datasets and ten HEST-1k cohorts, BCARP achieves the highest mean correlation-based performance against other baselines. Numerical results support biology-guided local-global residual propagation as an effective alternative to visual decoding for histology-to-transcriptomics prediction.

Accelerating Large-Scale Fingerprint Identification using Minutiae-Free Dynamic Graph Transformers

Binh An Nguyen, Luong Uy Nguyen, Van An Vu, Ngoc Nam Khuc, Tuan Linh Dang

Accepted at Signal Processing Letter (Q1)

BiometricsSecurity

Abstract: Fingerprint representation plays a central role in both verification and large-scale identification, where the quality of the learned descriptor directly determines matching accuracy, retrieval speed, and robustness to acquisition variability. Current deep learning approaches, from CNN-based methods such as DeepPrint to Vision transformer (ViT)-based frameworks such as AFR-Net, have significantly advanced generalized representation, yet they share a common limitation: patch-level features are aggregated through independent pooling mechanisms that discard structural relationships among discriminative regions. This paper introduces MDGT (Minutiae-free Dynamic Graph Transformer), a hybrid ViT-GNN framework that learns fingerprint representations enriched by structural token interaction. Experiments on FVC 2004 and FVC 2002 show that MDGT achieves Rank-1 identification rates of 97.92% and 98.41%, closely matching the current state of the art while being only 2.58 ms inference time, confirming that structural token interaction improves representation quality without compromising deployment efficiency.

From Prompts to Pareto Fronts: Using Code LMs as Semantic Genetic Operators for Compiler Bug Discovery

Lang Hong Nguyet Anh, Ho Viet Duc Luong, Vu Van An

Full paper Accepted at GECCO2026 (BPA nominated)

OptimizationCode LMs

Abstract: Differential compiler testing requires automatically generated programs that are not only diverse and bug-revealing, but also semantically well-defined and reproducible. Rule-based generators provide strong validity guarantees but offer limited control over semantic variation, while large language models (LLMs) can synthesize expressive programs without principled mechanisms for balancing competing testing objectives. This paper proposes LMOEC, a constrained multi-objective evolutionary framework that integrates code language models as semantic genetic operators within an NSGA-II search process. Instead of using the LLM as a one-shot generator, we employ it for population initialization, crossover, and mutation at the program level, enabling semantics-aware recombination while preserving strict admissibility constraints. Compiler test generation is formulated as a multi-objective optimization problem that simultaneously promotes structural diversity, cross-configuration output inconsistency, semantic complexity, and robustness to mutation. A constraint-driven acceptance pipeline enforces syntactic validity, deterministic execution, bounded runtime, and avoidance of undefined behavior before evolutionary selection. By maintaining a Pareto front of non-dominated programs, LMOEC preserves multiple high-value test archetypes reflecting different trade-offs between bug exposure and reproducibility. The framework demonstrates how expressive code models can be systematically embedded into evolutionary multi-objective optimization for reliability-critical software testing.
